💡 ¿Qué es Git y qué es GitHub?

Git es un sistema de control de versiones: guarda un historial de todos los cambios que se hacen sobre un conjunto de archivos, para poder ver ese historial o volver atrás si algo se daña.

GitHub es una plataforma en internet donde se alojan proyectos que usan Git (llamados repositorios), para que cualquiera con el link pueda verlos, descargarlos o colaborar en ellos.

🧠 Analogía para la clase: es parecido a una carpeta de Google Drive compartida, pero pensada para código, con un historial detallado de "quién cambió qué y cuándo".

🧰 Vocabulario básico

  • Repositorio (repo): la carpeta del proyecto alojada en GitHub. Ahí va a vivir todo el material del curso.
  • Commit: un "guardado" con una foto de cómo estaban los archivos en ese momento, más un mensaje que explica qué cambió.
  • Clonar / descargar: traer una copia del repositorio a tu propio computador.
  • README: el archivo de bienvenida/instrucciones que se ve automáticamente al entrar al repositorio.

Con estos cuatro términos es suficiente para que entiendas cómo moverte en el repositorio del curso.

🚀 Crear tu cuenta de GitHub (opcional)

No es obligatorio tener cuenta para ver el repositorio del curso, pero si quieres practicar y familiarizarte con la plataforma (te va a servir el resto de la carrera), estos son los pasos para crear la tuya con tu correo institucional:

  1. Entra a github.com y elige "Sign up".
  2. Regístrate usando tu correo institucional.
  3. Elige un nombre de usuario y una contraseña segura.
  4. Verifica tu cuenta desde el correo que te llega.
💡 No necesitas hacer nada más con esta cuenta por ahora — es solo para que sepas cómo se hace, por si más adelante quieres subir tus propios proyectos.

📂 Cómo entrar al repositorio del curso

Este es el repositorio donde vas a encontrar todo el material de la clase:

https://github.com/oviedo-coder/logica-programacion-2026-2

  1. Da clic en el link (también lo vas a encontrar siempre disponible en Classroom).
  2. Vas a ver una lista de carpetas, una por cada clase o semana.
  3. Entra a la carpeta de la clase que te interese para ver los ejercicios trabajados ese día.
  4. Da clic en cualquier archivo .java para leerlo directamente en el navegador.

📅 Qué vas a encontrar ahí cada semana

Después de cada clase se van a subir al repositorio los ejercicios que trabajamos ese día en clase, organizados por carpeta. Ahí vas a poder:

  • Revisar de nuevo el código que hicimos juntos en clase.
  • Estudiar y repasar antes de un parcial o un seguimiento.
  • Ponerte al día si faltaste a alguna clase.

Todo el material del curso queda disponible en un solo lugar y siempre actualizado.
